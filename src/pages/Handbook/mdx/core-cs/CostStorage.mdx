## 비용이 생기는 구조

<MermaidDiagram
  code={`flowchart LR
  subgraph store [저장]
    CAP["용량 (GB-월)"]
    PERF["프로비저닝 성능 (IOPS · 처리량)"]
  end
  subgraph access [접근]
    REQ["요청 수"]
    RET["조회 · 전송량"]
  end
  subgraph copy [복제본]
    SNAP["스냅샷 · 백업"]
  end
  store --> COST["스토리지 비용"]
  access --> COST
  copy --> COST`}
/>

저장 티어를 낮추면 **저장** 비용은 줄지만 **접근** 비용은 늘어난다. 접근 빈도를 모르는 채 티어를 바꾸면 오히려 비싸질 수 있다.
