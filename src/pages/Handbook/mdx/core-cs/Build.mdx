## 빌드 단계의 흐름

<MermaidDiagram
  code={`flowchart TB
  SRC["소스 체크아웃<br/>(커밋 고정)"] --> DEP["의존성 설치<br/>(lock 파일 기준)"]
  DEP --> CMP["컴파일 · 번들"]
  CMP --> PKG["패키징 · 이미지 빌드"]
  PKG --> OUT["산출물 + 메타데이터<br/>(버전 · 커밋 · 체크섬)"]
  CACHE["빌드 캐시"] -.-> DEP
  CACHE -.-> PKG
  OUT -->|"다음 단계"| TEST["테스트 · 보안 스캔"]`}
/>

같은 커밋에서 다시 빌드하면 같은 산출물이 나와야 한다. 그러려면 입력(소스 · 의존성 버전 · 베이스 이미지 · 빌드 도구 버전)이 모두 고정되어 있어야 하고, 산출물에는 어떤 커밋에서 나왔는지가 기록되어야 한다.

## 빌드 실패와 파이프라인

- 빌드가 실패하면 **테스트·배포 단계로 진행하지 않는다.** 실패 시 알림·로그로 원인을 빠르게 파악하고, 수정 후 다시 푸시하면 파이프라인이 재실행된다.
- 빌드만 통과하고 테스트가 실패한 경우에도 배포는 하지 않는 것이 일반적이다.
