## 알람이 울리는 흐름

<MermaidDiagram
  code={`flowchart LR
  BILL["청구 데이터<br/>(하루 수 회 갱신)"] --> BUD["예산 평가"]
  BUD -->|"실제 ≥ 80%"| N1["알림: 팀 채널"]
  BUD -->|"예측 ≥ 100%"| N2["알림: 팀 + 관리자"]
  BUD -->|"실제 ≥ 100%"| ACT["자동 조치<br/>(정책 부착 · 인스턴스 중지)"]
  N1 --> REV["원인 확인 · 조치"]
  N2 --> REV`}
/>

청구 데이터는 **하루에 몇 번** 갱신되므로 예산 알람은 실시간이 아니다. 몇 시간의 지연을 감안해 임계치를 조금 낮게 둔다.

<Callout variant="warning" title="예산은 상한이 아니라 신호다">
  <p>예산 알람이 울려도 리소스는 멈추지 않는다. 자동 조치를 붙이지 않는 한 예산은 통지 장치일 뿐이다. 프로덕션에 자동 중지를 붙이는 것은 위험하므로, 프로덕션은 알림 + 사람 대응, 비프로덕션은 자동 조치가 일반적이다.</p>
</Callout>
