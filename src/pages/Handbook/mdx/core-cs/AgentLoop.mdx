## 코드로 본 루프

모델이 "그만"이라고 하지 않아도 코드가 멈출 수 있어야 한다는 점이 핵심이다.

```python
def run_agent(goal, max_steps=20, budget_tokens=500_000, deadline_sec=300):
    state = load_or_create_state(goal)          # 중단된 작업이면 이어서
    started = now()

    for step in range(state.step, max_steps):
        if now() - started > deadline_sec:
            return stop(state, reason="timeout")
        if state.tokens_used > budget_tokens:
            return stop(state, reason="budget")

        context = build_context(state)          # Context Engineering
        output = call_model(context)
        state.tokens_used += output.usage

        if output.is_final_answer:
            return finish(state, output.text)

        call = validate_tool_call(output)       # 스키마 · 권한 검증
        if call.needs_approval:
            return pause_for_human(state, call)
        if state.is_repeating(call):
            state.add_note("같은 호출이 반복됨. 다른 방법을 시도할 것")
            continue

        result = execute_with_timeout(call)     # 실패도 결과로 기록
        state.record(step, call, summarize(result))
        save_checkpoint(state)                  # 재개 · 중복 실행 방지

    return stop(state, reason="max_steps")
```

재시도와 중복 실행 방지의 일반 원리는 <DocLink slug="retry-backoff">timeout / retry / backoff</DocLink>와 <DocLink slug="idempotency">Idempotency</DocLink> 문서와 같고, 오래 도는 Agent에 맞춘 적용은 <DocLink slug="agent-reliability">Reliability</DocLink>에서 다룬다. "사람 확인 필요"로 멈춘 뒤의 흐름은 <DocLink slug="agent-hitl">Human-in-the-Loop</DocLink>, 여러 루프를 엮는 방법은 <DocLink slug="agent-orchestration">Orchestration</DocLink>에 있다.
