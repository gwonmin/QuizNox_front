## Prompt Engineering

모델에게 지시하는 방식을 설계하여 원하는 결과를 이끌어내는 기법이다. Agent처럼 모델을 여러 번 부르는 시스템에서는 지시문뿐 아니라 도구 정의·검색 결과·기억까지 모델이 보는 전체 입력을 설계해야 하고, 이것은 <DocLink slug="context-engineering">Context Engineering</DocLink>에서 다룬다.

## 최신 모델 정보 확인하기

구체적인 모델 이름 · 가격 · 컨텍스트 크기는 이 핸드북에 적지 않는다. 아래 공식 문서와 비교 사이트에서 그때그때 확인한다. 리더보드는 측정 방식이 서로 다르므로(사람 선호 투표 vs 벤치마크 묶음) 한 곳의 순위만 보고 고르지 않는다.

## 에코시스템 메모: MCP

Model Context Protocol(MCP)은 LLM 클라이언트가 로컬 · 원격 도구와 데이터 소스에 붙기 위한 개방형 규약이다. 표준 자체가 권한 · 감사를 대신해 주지는 않으므로 허용 도구 목록 · OAuth · 감사 로그는 애플리케이션에서 설계한다. 자세한 내용은 <DocLink slug="agent-tool-use">Tool Use</DocLink>에 있다.
