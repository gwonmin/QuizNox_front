    ["멱등성", "쓰기 도구 호출마다 '작업 ID + 단계 번호' 같은 멱등 키를 붙인다."],
    ["Checkpoint · 재개", "단계가 끝날 때마다 상태를 저장하고, 재시작 시 끝난 단계는 건너뛴다."],
    ["큐 기반 실행", "긴 작업은 요청-응답 안에서 돌리지 않고 큐에 넣어 워커가 처리한다. 진행 상황은 따로 조회."],
    ["동시성 · 속도 제한", "모델 제공사 한도에 맞춰 워커 수와 초당 호출 수를 제한한다."],
    ["토큰 · 비용 예산", "작업 · 사용자 · 일 단위 상한. 넘기 전에 멈추고 부분 결과를 반환하거나 승인 요청."],
  ]}

## 중단 후 재개

<MermaidDiagram
  code={`flowchart TB
  S["재시작"] --> L["checkpoint 읽기"]
  L --> C{"다음 단계가 이미 실행됐나? (멱등 키로 확인)"}
  C -->|"예"| SKIP["결과만 읽고 다음 단계로"]
  C -->|"아니오"| RUN["실행 후 기록"]
  SKIP --> NEXT["계속"]
  RUN --> NEXT`}
/>

<Callout variant="warning" title="실행 전에 기록하고, 실행 후에 확정하기">
  <p>외부 부수 효과가 있는 단계는 "실행하려 함"을 먼저 기록하고 멱등 키를 붙여 호출한 뒤, 응답을 받으면 "완료"로 확정한다. 응답 전에 죽었다면 재개할 때 같은 멱등 키로 다시 호출해 외부 시스템이 중복을 걸러내게 한다.</p>
</Callout>
