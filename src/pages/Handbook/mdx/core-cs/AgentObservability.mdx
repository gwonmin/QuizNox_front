## 표준: OpenTelemetry GenAI 시맨틱 컨벤션

## 문맥 전파

도구 서버, 메시지 큐, 하위 Agent로 넘어갈 때 trace ID를 함께 넘기지 않으면 요청 하나가 여러 조각으로 끊어진다.

<KeyTable
  columns={["경계", "방법"]}
  rows={[
    ["HTTP · 도구 서버 호출", "W3C Trace Context 헤더(traceparent)를 전달"],
    ["큐 · 비동기 작업", "메시지 속성에 trace 문맥을 넣고 소비자가 이어받음"],
    ["대화 단위 연결", "session ID를 모든 span 속성(또는 baggage)에 넣어 대화 전체를 묶음"],
  ]}
/>
