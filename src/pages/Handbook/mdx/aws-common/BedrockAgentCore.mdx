## Gateway: API · Lambda → MCP

**Gateway**는 REST·OpenAPI·Lambda 핸들러를 **MCP 도구**로 래핑한다. 에이전트는 표준 tool schema로 호출하고, Gateway가 백엔드로 라우팅한다.

<MermaidDiagram
  code={`sequenceDiagram
  participant Agent
  participant Gateway
  participant Lambda
  Agent->>Gateway: MCP tool call
  Gateway->>Lambda: invoke with args
  Lambda-->>Gateway: result
  Gateway-->>Agent: tool result`}
/>

MCP 개념은 <DocLink slug="agent-tool-use">Tool Use · MCP</DocLink>를 본다.

## Browser · Nova Act

**Nova Act**는 브라우저 자동화에 특화된 에이전트·액트 계층이다. AgentCore **Browser** 도구와 결합하면 폼 입력·클릭·스크래핑 같은 UI 작업을 루프에 넣을 수 있다. 프로덕션에서는 Policy·Identity로 허용 도메인과 자격 증명을 제한한다.

## 프레임워크와의 관계

AgentCore는 LangChain · LangGraph · Strands · CrewAI 등 **어떤 에이전트 루프든** Runtime에 올리고, Gateway로 사내 API를 MCP화할 수 있다. 프레임워크 비교는 <DocLink slug="ai-agent">AI Agent</DocLink>를 본다.
