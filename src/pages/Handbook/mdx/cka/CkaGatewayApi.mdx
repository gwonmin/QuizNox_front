## 예시

```yaml
apiVersion: gateway.networking.k8s.io/v1
kind: Gateway
metadata:
  name: public
  namespace: shop
spec:
  gatewayClassName: nginx
  listeners:
  - name: http
    protocol: HTTP
    port: 80
---
apiVersion: gateway.networking.k8s.io/v1
kind: HTTPRoute
metadata:
  name: shop
  namespace: shop
spec:
  parentRefs:
  - name: public
  hostnames:
  - shop.example
  rules:
  - matches:
    - path:
        type: PathPrefix
        value: /
    backendRefs:
    - name: web
      port: 80
```

`gatewayClassName: nginx` 는 자리표시자다. `kubectl get gatewayclass` 에 있는 이름으로 바꾼다.

## 채점

```bash
kubectl get gateway,httproute -n shop
kubectl describe httproute shop -n shop
```
