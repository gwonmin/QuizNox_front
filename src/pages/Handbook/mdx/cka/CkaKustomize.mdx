## 예시

```yaml
apiVersion: kustomize.config.k8s.io/v1beta1
kind: Kustomization
resources:
- deployment.yaml
namespace: shop
namePrefix: prod-
replicas:
- name: web
  count: 3
images:
- name: nginx
  newTag: "1.27"
```

`deployment.yaml`의 Deployment 이름은 `web`, 컨테이너 이미지는 `nginx:1.25`라고 둔다.

```bash
kubectl kustomize shop
kubectl apply -k shop
```

## 채점

```bash
kubectl get deploy prod-web -n shop -o jsonpath='{.spec.replicas}{" "}{.spec.template.spec.containers[0].image}{"\n"}'
```
