## 예시

```bash
kubectl get svc,endpoints,pods -n shop -o wide
kubectl get netpol -n shop -o yaml
kubectl run curl --rm -it --restart=Never -n shop --image=curlimages/curl -- curl -sv --max-time 3 web.shop.svc
```

## 채점

```bash
kubectl get endpointslices -n shop
```
