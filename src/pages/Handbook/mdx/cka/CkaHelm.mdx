## 예시

```bash
helm upgrade --install web ./web-chart -n shop --create-namespace -f values.yaml
helm upgrade web ./web-chart -n shop --reuse-values --set replicaCount=3
helm history web -n shop
helm rollback web 1 -n shop
```

## 채점

```bash
helm list -n shop
helm get values web -n shop
kubectl get deploy -n shop
```
