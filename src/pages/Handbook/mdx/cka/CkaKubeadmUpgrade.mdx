## 예시

```bash
kubectl drain cp1 --ignore-daemonsets --delete-emptydir-data
sudo apt-get update && apt-cache madison kubeadm
sudo apt-mark unhold kubeadm
sudo apt-get install -y kubeadm=<madison에 나온 목표 패키지>
sudo kubeadm upgrade apply v1.35.0
sudo apt-mark unhold kubelet kubectl
sudo apt-get install -y kubelet=<같은 버전> kubectl=<같은 버전>
sudo systemctl daemon-reload && sudo systemctl restart kubelet
kubectl uncordon cp1
kubectl drain worker1 --ignore-daemonsets --delete-emptydir-data
```

`worker1`에 ssh 한 뒤에 실행한다. 이 노드에서는 `upgrade apply`를 쓰지 않는다.

```bash
sudo apt-mark unhold kubeadm
sudo apt-get install -y kubeadm=<같은 패키지>
sudo kubeadm upgrade node
sudo apt-mark unhold kubelet kubectl
sudo apt-get install -y kubelet=<같은 패키지> kubectl=<같은 패키지>
sudo systemctl daemon-reload && sudo systemctl restart kubelet
```

컨트롤 플레인으로 돌아와 `kubectl uncordon worker1` 을 실행한다.
