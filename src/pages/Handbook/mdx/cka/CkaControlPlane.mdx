## 예시

```bash
sudo crictl ps | grep -E 'kube-apiserver|etcd|kube-scheduler|kube-controller'
sudo crictl logs "$(sudo crictl ps -a --name kube-apiserver -q | head -n 1)" | tail
sudo vi /etc/kubernetes/manifests/kube-apiserver.yaml
```

## 채점

```bash
kubectl get pods -n kube-system -o wide | grep -E 'kube-apiserver|etcd|kube-scheduler|kube-controller'
```
