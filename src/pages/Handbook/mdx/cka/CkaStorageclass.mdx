## 예시

```bash
kubectl get storageclass -o custom-columns=NAME:.metadata.name,PROVISIONER:.provisioner
```

```yaml
apiVersion: storage.k8s.io/v1
kind: StorageClass
metadata:
  name: local-wait
provisioner: <위 목록의 provisioner>
reclaimPolicy: Delete
volumeBindingMode: WaitForFirstConsumer
```

## 채점

```bash
kubectl get storageclass local-wait
kubectl get pvc -A -o custom-columns=NAME:.metadata.name,CLASS:.spec.storageClassName,STATUS:.status.phase
```
