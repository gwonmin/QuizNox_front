## 예시

```yaml
apiVersion: v1
kind: Service
metadata:
  name: web
  namespace: shop
spec:
  type: NodePort
  selector:
    app: web
  ports:
  - port: 80
    targetPort: 8080
    nodePort: 30080
```

## 채점

```bash
kubectl get endpoints web -n shop
kubectl get svc web -n shop -o jsonpath='{.spec.type}{" "}{.spec.ports[0].nodePort}{"\n"}'
```
