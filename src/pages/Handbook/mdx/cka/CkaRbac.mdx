## 예시

```yaml
apiVersion: rbac.authorization.k8s.io/v1
kind: Role
metadata:
  name: pod-reader
  namespace: apps
rules:
- apiGroups: [""]
  resources: ["pods", "pods/log"]
  verbs: ["get", "list"]
---
apiVersion: rbac.authorization.k8s.io/v1
kind: RoleBinding
metadata:
  name: read-pods
  namespace: apps
subjects:
- kind: ServiceAccount
  name: viewer
  namespace: apps
roleRef:
  apiGroup: rbac.authorization.k8s.io
  kind: Role
  name: pod-reader
```

## 채점

```bash
kubectl auth can-i get pods --as=system:serviceaccount:apps:viewer -n apps
kubectl auth can-i get pods/log --as=system:serviceaccount:apps:viewer -n apps
kubectl auth can-i create pods --as=system:serviceaccount:apps:viewer -n apps
```
