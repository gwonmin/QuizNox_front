## 예시

```bash
sudo ETCDCTL_API=3 etcdctl snapshot save /opt/etcd-snapshot.db \
  --endpoints=https://127.0.0.1:2379 \
  --cacert=/etc/kubernetes/pki/etcd/ca.crt \
  --cert=/etc/kubernetes/pki/etcd/server.crt \
  --key=/etc/kubernetes/pki/etcd/server.key
sudo ETCDCTL_API=3 etcdctl snapshot status /opt/etcd-snapshot.db
sudo ETCDCTL_API=3 etcdctl snapshot restore /opt/etcd-snapshot.db --data-dir=/var/lib/etcd-restore
sudo sed -i 's#/var/lib/etcd#/var/lib/etcd-restore#g' /etc/kubernetes/manifests/etcd.yaml
```

## 채점

```bash
sudo ETCDCTL_API=3 etcdctl snapshot status /opt/etcd-snapshot.db
```
