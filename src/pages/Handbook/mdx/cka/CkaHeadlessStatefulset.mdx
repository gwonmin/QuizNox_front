## 예시

`storageClassName`을 적지 않으면 기본 StorageClass로 PVC를 만든다. 과제가 이름을 지정하면 그 이름을 `volumeClaimTemplates`에 적는다.

```yaml
apiVersion: v1
kind: Service
metadata:
  name: web
  namespace: shop
spec:
  clusterIP: None
  selector:
    app: web
  ports:
  - port: 80
    targetPort: 80
---
apiVersion: apps/v1
kind: StatefulSet
metadata:
  name: web
  namespace: shop
spec:
  serviceName: web
  replicas: 2
  selector:
    matchLabels:
      app: web
  template:
    metadata:
      labels:
        app: web
    spec:
      containers:
      - name: app
        image: nginx
        volumeMounts:
        - name: data
          mountPath: /usr/share/nginx/html
  volumeClaimTemplates:
  - metadata:
      name: data
    spec:
      accessModes: ["ReadWriteOnce"]
      resources:
        requests:
          storage: 1Gi
```

## 채점

```bash
kubectl get svc web -n shop -o jsonpath='{.spec.clusterIP}{"\n"}'
kubectl get pods,pvc -n shop
```
