## 예시

```bash
kubectl set image deploy/web app=nginx:1.27 -n shop
kubectl rollout status deploy/web -n shop
kubectl rollout history deploy/web -n shop
kubectl rollout undo deploy/web -n shop
kubectl scale deploy/web --replicas=3 -n shop
```

## 채점

```bash
kubectl get deploy web -n shop -o jsonpath='{.spec.template.spec.containers[0].image}{"\n"}'
kubectl rollout status deploy/web -n shop
```
