## 예시

```bash
kubectl config get-contexts
kubectl config use-context cluster1
kubectl create deployment web --image=nginx -n shop --dry-run=client -o yaml > web.yaml
kubectl create role pod-reader --verb=get --verb=list --resource=pods -n shop --dry-run=client -o yaml
kubectl get deploy web -n shop -o jsonpath='{.spec.template.spec.containers[0].image}{"\n"}'
kubectl explain service.spec.ports --recursive | head
```

## 채점

```bash
kubectl config current-context
kubectl get deploy web -n shop -o jsonpath='{.spec.template.spec.containers[0].image}{"\n"}'
```
