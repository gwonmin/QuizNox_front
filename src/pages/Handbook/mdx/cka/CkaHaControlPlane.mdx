## 예시

```bash
sudo kubeadm init --control-plane-endpoint 10.0.0.20:6443 --upload-certs --pod-network-cidr=10.244.0.0/16
# 추가 컨트롤 플레인
sudo kubeadm join 10.0.0.20:6443 --token <token> \
  --discovery-token-ca-cert-hash sha256:<hash> \
  --control-plane --certificate-key <key>
```
