## 예시

```bash
kubectl describe pod app -n shop
kubectl logs app -n shop --previous
kubectl get pod app -n shop -o jsonpath='{.status.containerStatuses[0].state}{"\n"}'
```

## 채점

```bash
kubectl get pod app -n shop
kubectl get pod app -n shop -o jsonpath='{.status.containerStatuses[0].restartCount}{"\n"}'
```
