## 예시

```yaml
apiVersion: v1
kind: ConfigMap
metadata:
  name: app-config
  namespace: shop
data:
  LOG_LEVEL: info
---
apiVersion: v1
kind: Secret
metadata:
  name: app-secret
  namespace: shop
type: Opaque
stringData:
  TOKEN: exam-value
---
apiVersion: v1
kind: Pod
metadata:
  name: app
  namespace: shop
spec:
  containers:
  - name: app
    image: nginx
    env:
    - name: LOG_LEVEL
      valueFrom:
        configMapKeyRef:
          name: app-config
          key: LOG_LEVEL
    volumeMounts:
    - name: token
      mountPath: /etc/secret
      readOnly: true
  volumes:
  - name: token
    secret:
      secretName: app-secret
```

## 채점

```bash
kubectl get configmap app-config -n shop -o jsonpath='{.data.LOG_LEVEL}{"\n"}'
kubectl get secret app-secret -n shop -o jsonpath='{.data.TOKEN}' | base64 -d; echo
kubectl exec -n shop app -- cat /etc/secret/TOKEN
```
